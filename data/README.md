# AirSource Dataset

## Dataset Source

India Air Quality Dataset (Kaggle):

https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india

## Dataset Information

This dataset contains historical air-quality measurements from monitoring stations across Indian cities.

## Required Columns

- PM2.5
- PM10
- NO2
- SO2
- CO
- O3
- AQI_Bucket

## Instructions

1. Download the dataset from Kaggle.
2. Extract the CSV file.
3. Rename it to `air_quality.csv`.
4. Place it inside this data folder.

Expected location:

`data/air_quality.csv`

**Note:** The dataset has not yet been uploaded to this repository. It contains historical observations, not live sensor readings.
